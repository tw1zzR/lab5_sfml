# Лабораторна робота №5 (Варіант 5)
**Тема:** Використання SFML в С++ проєкті. Відбиття об'єкта від стін.

## Опис проєкту
Програма візуально моделює фізичний процес рівномірного прямолінійного руху об'єкта у двовимірному замкненому просторі. При досягненні меж екрана відбувається абсолютно пружне зіткнення зі зміною напрямку відповідної складової швидкості на протилежний.

## Технології
* **Мова:** C++ (стандарт C++20)
* **Графічна бібліотека:** SFML 3.x
* **Система збирання:** CMake
* **Менеджер пакетів:** vcpkg (режим маніфесту)

## Керування моделлю (Клавіатура)
* **Space (Пробіл)** - Призупинити / відновити моделювання (Пауза).
* **R** - Перезапустити симуляцію (скидання у початкову точку).
* **Стрілка Вгору / Вниз** - Збільшити / зменшити швидкість руху об'єкта.
* **Стрілка Вліво / Вправо** - Змінити кут напрямку руху об'єкта.

## Запуск
Для успішної конфігурації проєкту за допомогою CMake необхідно вказати шлях до тулчейну `vcpkg`:
`-DCMAKE_TOOLCHAIN_FILE=C:/vcpkg/scripts/buildsystems/vcpkg.cmake`
